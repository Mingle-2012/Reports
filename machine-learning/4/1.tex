\subsection{随机二维数据的硬分隔与软分隔}
使用 \texttt{make\_classification} 生成二维线性可分数据，通过改变参数 $C$ 的大小观察决策边界的变化。

\subsubsection{代码}
\begin{lstlisting}[language=python]
X, y = make_classification(
    n_samples=200,
    n_features=2,
    n_informative=2,
    n_redundant=0,
    random_state=25
)
for C in [0.1, 1, 1e4]:
    clf = SVC(kernel='linear', C=C)
    clf.fit(X, y)
\end{lstlisting}

\subsubsection{结果}
如图 \ref{fig:svm_c} 所示，不同 $C$ 值下的决策边界有一定差异。当 $C$ 较大（如 $C=10^4$）时，SVM 更倾向于正确分类所有训练样本，决策边界较复杂；当 $C$ 较小（如 $C=0.1$）时，允许一定的误分类，决策边界更平滑。

\subsection{基于 Moons 数据集的 SVM 核技巧}
通过使用 linear、poly、rbf 三种核函数，比较不同核函数在非线性数据集上的分类效果。

\subsubsection{代码}
\begin{lstlisting}[language=python]
X, y = make_moons(n_samples=500, noise=0.2, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)
kernels = ["linear", "poly", "rbf"]
for k in kernels:
    clf = SVC(kernel=k, probability=True)

    y_pred = clf.predict(X_test)

\begin{lstlisting}[language=Python]
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_classification, load_iris, make_moons
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.metrics import precision_recall_curve, roc_curve, f1_score, auc

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

def part1_svm_hard_soft():
    X, y = make_classification(
        n_samples=200,
        n_features=2,
        n_informative=2,
        n_redundant=0,
        random_state=25
    )

    for C in [0.1, 1, 1e4]:
        clf = SVC(kernel='linear', C=C)
        clf.fit(X, y)
        title = f"SVM 决策边界 (C={C})"
        plt.figure(figsize=(6, 5))
        plt.scatter(X[:, 0], X[:, 1], c=y, cmap='bwr', s=30)

        xlim = plt.xlim()
        ylim = plt.ylim()
        xx = np.linspace(xlim[0], xlim[1], 200)
        yy = np.linspace(ylim[0], ylim[1], 200)
        YY, XX = np.meshgrid(yy, xx)
        xy = np.vstack([XX.ravel(), YY.ravel()]).T

        Z = clf.decision_function(xy).reshape(XX.shape)
        plt.contour(XX, YY, Z, colors='k', levels=[-1, 0, 1], linestyles=['--', '-', '--'])
        plt.title(title)
        plt.show()

def part2_iris_svm():
    iris = load_iris()
    X = iris.data
    y = iris.target

    X = X[y != 2]
    y = y[y != 2]

    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=0.3, random_state=42
    )

    scaler = StandardScaler()
    X_train = scaler.fit_transform(X_train)
    X_test = scaler.transform(X_test)

    clf = SVC(kernel='linear', probability=True)
    clf.fit(X_train, y_train)

    y_score = clf.predict_proba(X_test)[:, 1]

    precision, recall, _ = precision_recall_curve(y_test, y_score)
    plt.figure(figsize=(5, 4))
    plt.plot(recall, precision)
    plt.title("PR曲线 (Iris)")
    plt.xlabel("召回率")
    plt.ylabel("精确率")
    plt.grid()
    plt.show()

    fpr, tpr, _ = roc_curve(y_test, y_score)
    plt.figure(figsize=(5, 4))
    plt.plot(fpr, tpr)
    plt.title("ROC曲线 (Iris)")
    plt.xlabel("假阳性率")
    plt.ylabel("真阳性率")
    plt.grid()
    plt.show()

    y_pred = clf.predict(X_test)
    print("Iris F1 Score:", f1_score(y_test, y_pred))

def part3_moons_svm():
    X, y = make_moons(n_samples=500, noise=0.2, random_state=42)

    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=0.3, random_state=42
    )

    scaler = StandardScaler()
    X_train = scaler.fit_transform(X_train)
    X_test = scaler.transform(X_test)

    kernels = ["linear", "poly", "rbf"]

    for k in kernels:
        clf = SVC(kernel=k, probability=True)
        clf.fit(X_train, y_train)

        y_score = clf.predict_proba(X_test)[:, 1]
        y_pred = clf.predict(X_test)

        precision, recall, _ = precision_recall_curve(y_test, y_score)
        plt.figure(figsize=(5, 4))
        plt.plot(recall, precision)
        plt.title(f"PR曲线 (kernel={k})")
        plt.xlabel("召回率")
        plt.ylabel("精确率")
        plt.grid()
        plt.show()

        fpr, tpr, _ = roc_curve(y_test, y_score)
        plt.figure(figsize=(5, 4))
        plt.plot(fpr, tpr)
        plt.title(f"ROC曲线 (kernel={k})")
        plt.xlabel("假阳性率")
        plt.ylabel("真阳性率")
        plt.grid()
        plt.show()

        print(f"F1 分数 (kernel={k}):", f1_score(y_test, y_pred))

if __name__ == "__main__":
    part1_svm_hard_soft()
    part2_iris_svm()
    part3_moons_svm()
\end{lstlisting}
